# Exam Platform — экзаменационная платформа

Система для проведения компьютерных экзаменов в школах: сервер на **FastAPI**,
десктопный клиент ученика на **PyQt6** и веб-панель администратора на **React**.

Ученик запускает клиент, авторизуется по ФИО и школе, получает вариант задания,
отвечает на вопросы под контролем лока (запрет браузеров) и таймера. Администратор
через веб-панель управляет вариантами, заданиями, школами, таблицами перевода
баллов, смотрит результаты и статистику.

---

## Архитектура

```
┌──────────────────┐   HTTP/JSON    ┌──────────────────────┐
│  student/        │ ◄────────────► │  server/             │
│  PyQt6-клиент    │                │  FastAPI + SQLAlchemy│
│  (экзамен у      │                │  SQLite / PostgreSQL │
│   ученика)       │                └──────────┬───────────┘
└──────────────────┘                           │ REST API /api/*
                                    ┌──────────┴───────────┐
                                    │  web/                │
                                    │  React + Vite + TS   │
                                    │  админ-панель        │
                                    └──────────────────────┘
```

Сервер при запуске раздаёт собранный фронтенд (`web/dist`) как статику, поэтому
для работы достаточно одного запущенного процесса `server` (режим «всё в одном»).

### Компоненты

| Каталог   | Технологии                                             | Назначение                                     |
|-----------|--------------------------------------------------------|------------------------------------------------|
| `server/` | Python 3.14, FastAPI, SQLAlchemy 2, Alembic, PyJWT, Argon2 | REST API, хранение данных, проверка ответов |
| `student/`| Python 3.14, PyQt6, requests, psutil                   | Клиент ученика: экзамен, локер, автосохранение |
| `web/`    | React 19, TypeScript, Vite, Ant Design, Axios          | Панель администратора                          |

## Возможности

**Сервер / админ-панель**
- Управление школами, учениками и вариантами заданий;
- Задания с полями ввода (строка / число) и двумя схемами оценивания:
  «всё или ничего» и частичные баллы;
- Загрузка файлов-вложений к заданиям;
- Таблицы перевода первичных баллов в отметки с активацией одной таблицы;
- Просмотр попыток, результатов и статистики, очистка результатов
  (по попытке / ученику / всем);
- Настройки экзамена (длительность по умолчанию и др.);
- JWT-авторизация администраторов, хеширование паролей Argon2;
- Аудит-лог действий администратора.

**Клиент ученика**
- Вход по ФИО и школе, получение своего варианта;
- Таймер экзамена, автосохранение ответов каждые N секунд;
- Периодическая синхронизация ответов и событий с сервером;
- Локер: блокировка браузеров (настраиваемый чёрный список процессов),
  сворачивание окна и попытки выхода фиксируются как события;
- Сбор телеметрии (переключение фокуса, запуск сторонних процессов).

## Требования

- **Python 3.14** (оба Python-компонента)
- **Poetry** (управление зависимостями)
- **Node.js 20+** и npm (только для сборки веб-панели)
- Для клиента ученика — Windows (локер рассчитан на процессы Windows)

## Быстрый старт

### 1. Сервер

```bash
cd server
poetry install
cp .env.example .env        # при необходимости отредактируйте DATABASE_URL, SECRET_KEY
poetry run uvicorn app.main:app --host 0.0.0.0 --port 8000
```

При первом запуске:
- создаётся схема БД (SQLite `exam.db` по умолчанию);
- сидируются школы, настройки и администратор по умолчанию
  (`admin` / `admin12345` — задайте свои значения через `.env`);
- в консоли печатается адрес, который нужно указать клиентам.

Документация API доступна по `http://localhost:8000/docs`.

### 2. Веб-панель администратора

Вариант А — режим «всё в одном» (рекомендуется):

```bash
cd web
npm install
npm run build               # собирает web/dist, сервер раздаёт её сам на :8000
```

Вариант Б — разработка с hot reload:

```bash
cd web
npm run dev                 # http://localhost:5173, запросы идут на сервер
```

### 3. Клиент ученика

```bash
cd student
poetry install
poetry run python -m examclient.main
```

Перед запуском отредактируйте `student/config.json`:

```jsonc
{
  "server_url": "http://192.168.0.105:8000", // адрес вашего сервера
  "machine_id": "pc-01",                     // уникальный id компьютера в аудитории
  "autosave_seconds": 20,                    // период автосохранения ответов
  "sync_seconds": 30,                        // период синхронизации событий
  "locker": {
    "enabled": true,                         // включён ли локер
    "poll_ms": 800,                          // период опроса процессов
    "blacklist": ["chrome.exe", "..."]       // блокируемые процессы
  }
}
```

## Сборка исполняемых файлов (PyInstaller)

Оба компонента имеют готовые spec-файлы для сборки под Windows:

```bash
# сервер (консольное приложение ExamServer, включает web/dist)
cd server
poetry run pyinstaller build_server.spec

# клиент ученика (без консоли, ExamClient)
cd student
poetry run pyinstaller build_client.spec
```

Готовые бинарники появятся в `dist/`. Точки входа — `exe_entry.py` и
`client_entry.py` соответственно.

## Работа с базой данных

- **Разработка:** SQLite — файл `server/exam.db`, дополнительных сервисов не нужен.
- **Продакшен:** PostgreSQL — укажите в `.env`
  `DATABASE_URL=postgresql+psycopg2://user:pass@host:5432/exam`.
- **Миграции (Alembic):**

```bash
cd server
poetry run alembic revision --autogenerate -m "описание изменения"
poetry run alembic upgrade head
```

### Вспомогательные скрипты

```bash
cd server
poetry run python -m tools.reset_admin   # сброс/создание администратора
poetry run python -m tools.seed_demo     # демо-данные для проверки потока ученика
```

## Основные эндпоинты API

| Префикс            | Доступ        | Назначение                                      |
|--------------------|---------------|--------------------------------------------------|
| `/api/auth/login`  | публичный     | вход администратора, выдача JWT                  |
| `/api/public`      | публичный     | поиск школы/ученика, информация об экзамене      |
| `/api/student`     | токен ученика | старт попытки, варианты, ответы, события, финиш  |
| `/api/admin`       | JWT админа    | школы, варианты, задания, таблицы, настройки, результаты, статистика |
| `/api/files`       | JWT / ученик  | загрузка и отдача вложений заданий               |

Полный список — в Swagger UI: `/docs`.

## Конфигурация сервера (`.env`)

| Переменная                        | Описание                                        |
|-----------------------------------|--------------------------------------------------|
| `DATABASE_URL`                    | строка подключения к БД                          |
| `SERVER_HOST` / `SERVER_PORT`     | адрес и порт прослушивания                       |
| `SECRET_KEY`                      | ключ подписи JWT (обязательно замените!)         |
| `ACCESS_TOKEN_EXPIRE_MINUTES`     | срок жизни токена (по умолчанию 720 = 12 часов)  |
| `DEFAULT_ADMIN_USERNAME/PASSWORD` | админ, создаваемый при первом запуске            |
| `STORAGE_PATH`                    | каталог для загруженных файлов                   |
| `MAX_UPLOAD_SIZE_MB`              | ограничение размера загрузки                      |
| `DEFAULT_EXAM_DURATION_MINUTES`   | длительность экзамена по умолчанию               |
| `APP_ENV` / `DEBUG`               | режим окружения                                  |
